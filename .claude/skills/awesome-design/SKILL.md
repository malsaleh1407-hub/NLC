# Awesome Design (DESIGN.md library)

Source: https://github.com/VoltAgent/awesome-design-md

Each folder in `design-md/<brand>/` holds a `DESIGN.md` describing that site's design system.

1. List available brands: `ls <skill-dir>/design-md/`
2. Read the matching `design-md/<brand>/DESIGN.md` (only the one(s) needed).
3. Apply its tokens, type scale, spacing, and component patterns to the target UI, adapting to the project's own brand colors and fonts where they exist (for NLC: `--primary #24285e`, `--secondary #F6851F`, Bizmo/Outfit EN, Cairo AR RTL).
